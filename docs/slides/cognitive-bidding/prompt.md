## Cognitive Bidding

It is cognitive because each edge agent reasons over multiple live factors before deciding:

Can I do this job safely?
Am I already overloaded?
How far am I from the job location?
Will accepting this job delay my current commitments?
Am I healthy enough to perform efficiently?
Is another machine likely better suited than me?

So the bid is really a smart self-assessment of:

capability
confidence
cost
timing
risk
operational fitness
